# Compiler dependency notices

These license texts, package metadata and notices accompany the unmodified
official UndertaleModCli0.9.2.0 helper. The actual published compiler dependency
list comes from its `UndertaleModCli.deps.json`. `provenance.json` records the
NuGet package SHA256/size, upstream source commits, individual source and published
hashes. Text differs only by CRLF-to-LF normalization.

- Magick.NET14.16.0: Apache2.0 plus the complete upstream native-library notices.
- Roslyn5.9.0: MIT plus each package's third-party notices.
- Newtonsoft.Json13.0.4: MIT license distributed in its NuGet package.
- SharpZipLib1.4.2: MIT, license from the package's exact source commit.
- System.CommandLine2.0.11: MIT, license from its recorded dotnet source commit.
- CoreCompat.System.Drawing6.0.5.128: upstream permission license and package
  metadata/copyright; the helper's Windows package includes this managed assembly.

The compiler's GPL3 and Underanalyzer's MPL2 licenses and corresponding source
are additionally included under `licenses/beta-dependencies` and
`third-party-source` when building the portable beta package. .NET notices are
under `licenses/dotnet`. Python/Pillow retain their bundled notices. This inventory
does not assign a license to ROUTEKEEPER or claim independent legal certification.
